# logreader/ Directory

## Purpose
Web-based application for browsing and inspecting LLaMEA conversation logs in real-time.

## Overview
Minimal Flask application providing a user-friendly interface to explore JSONL conversation logs generated by LLaMEA experiments.

## File Structure

### `app.py`
Main Flask application server.

**Features:**
- Loads JSONL conversation log
- Serves web interface
- Streams conversation messages
- Provides search/filter capabilities

**Usage:**
```bash
# Default: loads conversationlog.jsonl from current directory
python logreader/app.py

# Specify log file
python logreader/app.py --logfile path/to/conversationlog.jsonl

# Or use environment variable
export CONVERSATION_LOG=path/to/conversationlog.jsonl
python logreader/app.py
```

**Endpoint:** `http://localhost:5001`

### `static/`
Static assets for web interface.

#### `css/style.css`
Styling for conversation viewer.
- Clean, readable message display
- Syntax highlighting for code blocks
- Responsive design
- Dark/light mode support (likely)

#### `js/script.js`
Client-side interactivity.
- Load and display messages
- Search/filter conversations
- Code block highlighting
- Navigation between messages

### `templates/`
HTML templates for Flask.

#### `index.html`
Main conversation viewer interface.
- Message list
- Code block rendering
- Search bar
- Navigation controls
- Timestamps

## Features

### Conversation Browsing
- View all LLM interactions chronologically
- See prompts sent to LLM
- See responses from LLM
- Timestamps for each message

### Code Highlighting
- Syntax highlighting for Python code blocks
- Markdown rendering for formatted text
- Collapsible long messages

### Search and Filter
- Search by content
- Filter by role (user/assistant)
- Jump to specific generations

### Real-Time Updates
- Can reload to see new messages
- Useful for monitoring running experiments

## Dependencies
- `Flask` - Web framework
- `jsonlines` - JSONL parsing
- `argparse` (builtin) - CLI arguments

## Usage Scenarios

### Debugging Prompts
```bash
# Run experiment
python main-evolutionary.py &

# In another terminal, monitor logs
python logreader/app.py --logfile LLaMEA-{model}-{name}/conversationlog.jsonl

# Open browser to localhost:5001
# See prompts and responses in real-time
```

### Post-Experiment Analysis
```bash
# After experiment completes
python logreader/app.py --logfile exp-11-20_120000-gpt4-test/conversationlog.jsonl

# Browse to understand:
# - Why certain algorithms were generated
# - How prompts evolved
# - What feedback was provided
```

### Comparing Experiments
```bash
# Terminal 1
python logreader/app.py --logfile experiment_A/conversationlog.jsonl

# Terminal 2 (different port)
# (Would need to modify app.py to use different port)
python logreader/app.py --logfile experiment_B/conversationlog.jsonl
```

## Configuration

### Default Log File

```python
# In app.py

```

### Port
```python
# In app.py
app.run(host='localhost', port=5001)
```

### Environment Variable
```bash
export CONVERSATION_LOG=/path/to/log.jsonl
python logreader/app.py
```

## Advantages

### vs. Reading JSONL Directly
- ✅ Human-readable formatting
- ✅ Code syntax highlighting
- ✅ No need to parse JSON manually
- ✅ Search and navigation
- ✅ Better for long conversations

### vs. Text Editor
- ✅ Structured view
- ✅ Collapsible sections
- ✅ Timestamp navigation
- ✅ Role-based filtering

### vs. Command-Line Tools (jq, grep)
- ✅ Visual interface
- ✅ No command-line expertise needed
- ✅ Context preservation
- ✅ Easier to share with collaborators

## Limitations
- **No editing:** Read-only viewer
- **No persistence:** No state across reloads
- **Single file:** Loads one log at a time
- **Memory:** Large logs may be slow
- **No authentication:** Local use only

## Security Considerations
- **Local only:** Binds to localhost
- **No sensitive data exposure:** Logs may contain API keys in prompts
- **Not for production:** Development-quality code
- **Trust logs:** No input validation (trusts log file format)

## Troubleshooting

### Port 5001 already in use
```bash
# Find and kill process
lsof -i :5001
kill <PID>

# Or modify app.py to use different port
```

### Log file not found
```bash
# Verify path
ls -l conversationlog.jsonl

# Use absolute path
python logreader/app.py --logfile /full/path/to/log.jsonl
```

### No messages displayed
- Check JSONL format (one JSON object per line)
- Verify file is not empty
- Check browser console for JavaScript errors

## Development
To modify the app:

1. **Add features to app.py:**
   ```python
   @app.route('/api/stats')
   def get_stats():
       # Return conversation statistics
       pass
   ```

2. **Update templates/index.html:**
   ```html
   <div id="stats"></div>
   ```

3. **Update static/js/script.js:**
   ```javascript
   fetch('/api/stats')
       .then(res => res.json())
       .then(data => displayStats(data));
   ```
